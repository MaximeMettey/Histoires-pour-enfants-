# Assets nécessaires

Pour que l'application fonctionne correctement, vous devez ajouter les images suivantes dans ce dossier :

## Images requises

1. **icon.png** (1024x1024 px)
   - L'icône principale de l'application
   - Format : PNG avec fond transparent ou couleur unie

2. **adaptive-icon.png** (1024x1024 px)
   - Icône adaptative pour Android
   - Format : PNG

3. **splash.png** (1284x2778 px minimum)
   - Image de démarrage de l'application
   - Fond couleur : #FFE5B4 (ou personnalisé)

4. **favicon.png** (48x48 px)
   - Favicon pour la version web
   - Format : PNG

## Note

Ces fichiers sont optionnels pour le développement. L'application fonctionnera même sans eux, mais ils sont nécessaires pour la production.

Vous pouvez créer des images temporaires ou utiliser des générateurs d'icônes en ligne comme :
- https://www.appicon.co/
- https://icon.kitchen/
